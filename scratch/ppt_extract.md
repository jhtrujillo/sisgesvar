01 · CONTEXTO El ciclo de mejoramiento y el flujo de datos Informe de avances · Módulos de Mejoramiento · SIVAR — CENICAÑA · 2026 4 Los tres módulos no son islas: la salida de uno es la entrada del siguiente. La trazabilidad recorre toda la cadena, del campo a la decisión de cruzamiento. Cada rasgo tiene un peso (importancia) y un nivel máximo tolerado, y ambos dependen del proyecto y del ambiente. Ponderado (peso) Importancia relativa de la característica dentro del valor de mérito. ## ppt/slides/slide12.xml
02 · CRUZAMIENTOS · MATEMÁTICA Restricciones biológicas del motor Informe de avances · Módulos de Mejoramiento · SIVAR — CENICAÑA · 2026 12 Antes de puntuar nada, el motor filtra lo biológicamente imposible. Dos restricciones acotan el universo de cruces candidatos. 1 · Sincronización de floración El motor solo considera flores con fecha en la ventana [ayer, hoy], estado = 0 y bolsa_común = 0. Fundamento biológico: solo puede cruzarse el polen y la flor que están receptivos simultáneamente. 2 · Dirección del cruce (sexo) Cada cruce es dirigido: madre (A) × padre (B). El par se descarta si A no es femenino o B no es masculino. A = Madre  ♀    Hembra · HF · HD B = Padre  ♂    Macho · MF · MD
## ppt/slides/slide13.xml
02 · CRUZAMIENTOS · MATEMÁTICA De valor crudo a “nivel” Informe de avances · Módulos de Mejoramiento · SIVAR — CENICAÑA · 2026 13 El corazón del cálculo: cada medición de campo se convierte en un nivel comparable. Así se pueden sumar rasgos tan distintos como sacarosa, altura y roya. Rasgos productivos Se expresan relativos al testigo (control). Ej.: TCHM, sacarosa, altura, población, diámetro, volcamiento. índice = (valor × 100) / testigo Enfermedades (roya) Se usa el valor de incidencia directo (%). Ej.: roya café, roya naranja. nivel = valor (%) Discretización El índice se convierte en un nivel mediante rangos configurables, en dos escalas: viabilidad y mérito. nivel = calificación(índice) Dato faltante Penalización explícita para no premiar información ausente. 999 (viabilidad) · 0 (mérito)
## ppt/slides/slide14.xml
02 · CRUZAMIENTOS · MATEMÁTICA Fórmula de Viabilidad Informe de avances · Módulos de Mejoramiento · SIVAR — CENICAÑA · 2026 14 Para cada característica con peso, la suma de niveles de los dos padres no puede superar el nivel máximo tolerado. Basta que una falle para descartar el cruce. Viable c   =  (Nivel A,c  + Nivel B,c )  ≤  Nivel máx,c Se evalúa por característica Solo entran las características con ponderado &gt; 0. Regla del eslabón débil Si una sola característica falla el umbral, el cruce completo se marca no viable. Enfermedades siempre pesan Roya y otras se evalúan aunque no haya testigo del rasgo. Fuente de dato con respaldo Si falta el valor, se busca en la jerarquía BG → Prueba Regional → Estado III.

Se calcula por característica y se acumula para cada padre. VM parcial  = (Pond × Nivel mérito ) / 100 VM total  = Σ VM parcial Un score por padre Se calcula VM para la madre (A) y otro para el padre (B) del par.
